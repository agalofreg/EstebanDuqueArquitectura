# Duque Obra · prototipo navegable

Dos archivos, sin dependencias ni build. Datos ilustrativos.

- `index.html`: el prototipo navegable de la plataforma.
- `como-funciona.html`: documento de apoyo para la reunión. Explica de dónde sale cada dato, el flujo paso a paso con lo que cambia frente a Backbone, y la comparación final. En la sección Paso a paso se avanza con las flechas del teclado.

Qué se puede recorrer:
- Inicio del estudio con la lectura diaria generada, indicadores y filtros por estado
- Ficha de cada proyecto con cinco pestañas: Resumen, Cronograma, Actas, Pagos, Fotos
- Actas con el documento original y los compromisos extraídos y comparados
- Registro de un pago con soporte, que aparece de inmediato en la tabla
- Alta de un cliente nuevo con la creación automática de carpeta, registro y acceso
- Panel "Pregúntale a tus proyectos" (Fase 2)
- "Así lo ve el cliente": desde cualquier proyecto o desde Clientes, la vista que recibe el cliente final

Diseñado para navegador de escritorio a pantalla completa. Cada pantalla tiene su propia dirección, por ejemplo `#/proyecto/cedro/actas`, para compartir un enlace directo.

## Publicar en GitHub Pages
1. Suba `index.html` y este README a un repositorio.
2. Settings → Pages → rama `main`, carpeta `/root`.
3. En uno o dos minutos queda en `https://<usuario>.github.io/<repositorio>/`.
